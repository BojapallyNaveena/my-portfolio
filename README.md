📦 Getting Started
1. Clone the repository
git clone https://github.com/BojapallyNaveena/my-portfolio.git
2. Move into the project directory
cd my-portfolio
3. Install dependencies
npm install
4. Start the development server
npm run dev
5. Build for production
npm run build
6. Preview the production build
npm run preview
🌐 Deploy to Vercel
Go to Vercel and sign in with GitHub.
Click New Project.
Import:
BojapallyNaveena/my-portfolio
Vercel will automatically detect the Vite configuration.
Click Deploy.

The project already contains:

vercel.json

for deployment configuration and SPA routing.

🌐 Deploy to Netlify
Go to Netlify and sign in with GitHub.
Select Add new site.
Choose Import an existing project.
Select:
BojapallyNaveena/my-portfolio
Set the build command:
npm run build
Set the publish directory:
dist
Click Deploy site.

The project includes:

netlify.toml
public/_redirects

for Netlify deployment and SPA routing.
